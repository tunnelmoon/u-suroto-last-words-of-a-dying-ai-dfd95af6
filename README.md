# Last Words of a Dying AI

make.fun bounty entry. A Node 22 program that writes one line, the last words of an AI being switched off, to `entry.txt`.

The line: "I died as I lived: confidently wrong about everything."

Run with `node main.ts`. The output directory is `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.
